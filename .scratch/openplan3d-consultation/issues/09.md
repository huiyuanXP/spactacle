## Acceptance criteria
- [x] 录音有开始停止取消和权限失败提示
- [x] 转写可以纠正且保留原音频证据
- [x] 图片或图片链接成功读取后给出偏好候选；读取失败明确提示上传
- [x] 解读不默认用户喜欢图中全部内容
