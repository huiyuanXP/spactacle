# 09 — 语音与参考图片输入

**What to build:** 悬浮聊天中录音或上传参考图，转写/解读后由用户确认。

**Blocked by:** 03 — 悬浮聊天与Pi流式咨询; 04 — 推荐式追问与一键采用建议

**Status:** ready-for-agent
**Phase:** Week 2 / Phase 1
**建议负责人:** 后端主导
**粗估:** 1–1.5人日（待接入探针校准）

## Acceptance criteria
- [ ] 录音有开始停止取消和权限失败提示
- [ ] 转写可以纠正且保留原音频证据
- [ ] 图片或图片链接成功读取后给出偏好候选；读取失败明确提示上传
- [ ] 解读不默认用户喜欢图中全部内容
- [ ] 采用偏好后可追溯消息/附件/区域并更新需求面板
- [ ] 附件隔离项目权限并限制大小和支持类型

## 验证边界
验证端到端可见行为与对应错误分支；数据一致性、权限和并发必须覆盖。实际命令由开工时的仓库发现，不把建议命令冒充已有验证。
不实现后续票；没有AI生图任务。遵循用户草图、选定OpenPlan3D、Pi和共享确认语义。
