# 06 — 点击家具弹出属性编辑器

**What to build:** 点击家具打开带尺寸、颜色、高度和材质控件的对象弹窗，编辑后保存。

**Blocked by:** 01 — OpenPlan3D接入与可恢复工作台; 02 — 右侧房间需求面板与房间定位

**Status:** ready-for-agent
**Phase:** Week 2 / Phase 1
**建议负责人:** 前端主导
**粗估:** 1–1.5人日（待接入探针校准）

## Acceptance criteria
- [ ] 3D点击得到稳定object_id并高亮当前家具
- [ ] 弹窗不越屏，关闭后焦点恢复
- [ ] 宽深、物件高度与离地高度清晰区分并显示单位
- [ ] 支持的颜色材质修改在场景可见，不支持的属性禁用并解释
- [ ] 属性提交通过后端校验并产生revision；失败恢复上个提交状态

## 验证边界
验证端到端可见行为与对应错误分支；数据一致性、权限和并发必须覆盖。实际命令由开工时的仓库发现，不把建议命令冒充已有验证。
不实现后续票；没有AI生图任务。遵循用户草图、选定OpenPlan3D、Pi和共享确认语义。
