## Acceptance criteria
- [x] 消息与project/room/object ID共同保存
- [x] 切换对象后聊天上下文不会继续指向旧对象
- [x] 受支持的尺寸/颜色/材质修改可预览并确认
- [x] 不存在的对象、资产和非法参数返回结构化错误
- [x] 正式方案修改须明确用户授权，参考建议维持未采用标记
