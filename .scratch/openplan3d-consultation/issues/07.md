# 07 — 家具局部聊天与受限修改工具

**What to build:** 在家具弹窗中用文字要求修改，Agent只修改明确选中的对象。

**Blocked by:** 03 — 悬浮聊天与Pi流式咨询; 06 — 点击家具弹出属性编辑器

**Status:** ready-for-agent
**Phase:** Week 2 / Phase 1
**建议负责人:** 后端主导
**粗估:** 1–1.5人日（待接入探针校准）

## Acceptance criteria
- [ ] 消息与project/room/object ID共同保存
- [ ] 切换对象后聊天上下文不会继续指向旧对象
- [ ] 受支持的尺寸/颜色/材质修改可预览并确认
- [ ] 不存在的对象、资产和非法参数返回结构化错误
- [ ] 正式方案修改须明确用户授权，参考建议维持未采用标记
- [ ] 后端工具不执行任意代码或任意场景脚本

## 验证边界
验证端到端可见行为与对应错误分支；数据一致性、权限和并发必须覆盖。实际命令由开工时的仓库发现，不把建议命令冒充已有验证。
不实现后续票；没有AI生图任务。遵循用户草图、选定OpenPlan3D、Pi和共享确认语义。
