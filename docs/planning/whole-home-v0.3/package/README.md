# ROOMNOTE 全屋版规划包

版本：v0.3-planning / 2026-09-14。

## 推荐阅读顺序

打开 `ROOMNOTE_review.html`：三个页签依次为项目状态、实施计划、视觉确认清单。HTML已内嵌36张独立参考图，无需联网。点击图片可放大；意见仅存本机浏览器，使用“导出确认意见 JSON”留存并回传。导入功能只读取此清单的意见格式，不执行代码或服务器操作。

`01_project_status.pdf` 是状态、来源与接手操作说明；`02_implementation_plan.pdf` 是8目标、16工作包与验收计划；`03_visual_confirmation_checklist.pdf` 是36场景的打印确认图册。`images/` 为36张1600×1000独立PNG；`editable/` 保留Markdown正文、场景/工作包JSON、空白确认模板与CSV追踪矩阵。

## 边界

设计确认不是代码验收、施工批准或部署授权。01–10按旧范围有代码验收，新的全屋版没有因此完成。最新CURRENT记录Week2发布包已准备但待宿主操作批准；本轮未再次通过健康检查或测试，没有改服务器。照片式空间底图只作目标风格参考，尺寸与房屋结构不能据此认定。

此包不会自动更新服务器Spec/PLAN/CURRENT。批准设计后，仍需在获授权的后续轮次写入增量规格和票据。旧week1=01–05、week2=06–10、week3=11–16保持不变；WH-xx是计划工作包，不是重新编号的旧票。

## 计数

3份文档，8个产品目标，16个增量工作包，36张独立UI参考图，108条场景验收条件，36条场景设计问题，16项全局确认。所有新范围验收均未预填通过。

来源见各文末或 `editable/sources.md`。不包含密钥、业主数据库、宿主凭据或独立字体文件。
