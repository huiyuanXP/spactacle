## 如何确认

本清单是设计目标，不是软件通过报告。请分别确认视觉布局、用户动作、数据影响和失败处理。每个场景有独立参考图；在HTML版可放大图片、选择“同意设计 / 需要调整 / 暂不纳入 / 待确认”并填写意见，结果只存本机浏览器，可导出JSON。选“同意设计”不会更新服务器票据、批准施工或授权部署。

图中的房屋、面积、预算、家具尺寸、版本和分类均为示例。全屋风格源自用户目标图；局部室内插画仅用于视觉讨论。所有状态说明重新整理自代码/文档证据，不能从生成图推断当前实现。图中的3个数字标记对应底部3条阅读指引；实际实现仍须按下方验收验证。

用户已经确定：全屋交付、家具更改、房间用途更改、非承重墙体受控拆改、WASD移动与视角调整。未确定的具体输入格式、专业核实角色、移动端等级与工期见D01–D16；不重复把已确定的大方向当成待选择。
