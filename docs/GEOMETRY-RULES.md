# 占用体积规则 v1（ticket10）

全部尺寸为 cm，角度为度。场景 x/y 对应原生 x/z；场景正旋转对应原生绕 y 负旋转。矩形角点用 width × scale.x、depth × scale.y；垂直区间用楼层 elevation（缺省 level × 300）、家具 elevation 和 height。非单位 scale.z 尚不支持，标记无法判断。

碰撞使用两个旋转矩形的四个 SAT 法线轴，再检查垂直重叠；每个方向均超过 1 cm 才触发。接触及 <=1 cm 重叠不触发。rug、round_rug、runner_rug 作为有意铺垫排除家具碰撞；仍检查房间边界。结果是保守占用包围体，不是精确网格物理检测，也不是工程安全认证。

房间按 sidecar wall_ids 连接墙中心线成闭合直线多边形。弯曲、缺失、未闭合、自交边界以及无法唯一绑定房间产生“无法判断”。矩形四角包含检查加边与边穿越检查可发现凹边界越界；边界数值容差 0.01 cm。不扣除墙厚，不判断门扇活动区或建筑结构。

诊断由服务器在项目创建、scene_changed/object_changed 的同一数据库事务内重算，沿用原有权限、CAS、幂等命令、revision/outbox。ID 为 rule/version/排序后的对象 IDs；消失的诊断保留 resolved 状态、首次及最后版本。未有诊断不代表已安全。

原生 viewer 仅在真实渲染时通过已验证来源的 bridge 发送投影，React 标记按对象 ID 绑定，不轮询相机。未保存预览或物件编辑器打开时隐藏正式场景标记。每个对象合并一个提醒入口，详情展示规则、依据、影响对象和处理建议。

验收样例：tests/geometry.test.ts 与 tests/browser/10-geometry.spec.ts。当前实现/验收限制以 ticket10 最新执行回执为准。

## 2026-09-13 加固
拒绝零长度边、重复顶点、零面积、回折共线边、非相邻边接触/重叠以及未闭合/曲线/非有限坐标。凹多边形样例专门覆盖四角在内但边穿过凹口。楼层 level 限 -100..100，elevation 限 -30000..30000 cm，非有限或错误类型由场景 API 拒绝。旧项目读取时仅派生诊断，不写数据库；下一次受支持事务持久化。问题索引列出所有规则和已解决历史，同一对象多个问题均可选择。

## 已确认参考家具的一致性边界

参考家具的正式需求绑定原房间与楼层。当前版本不提供跨房间迁移确认流程，因此已采用参考家具跨房间/楼层移动会被事务拒绝，不会静默更新原房间需求。已采用对象必须保留明确尺寸，且独立 scale.x/y/z 必须为1；修改尺寸请使用属性字段。未采用对象带非单位缩放时，采用操作会明确拒绝并保留待确认状态。普通非参考家具及尚未采用的越界参考仍可触发几何诊断，这些约束不把所有移动或全部场景编辑禁用。
