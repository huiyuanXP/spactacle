1. 建立 monorepo、数据库迁移、同源API、单业主认证与项目保存恢复。
2. 对选定 OpenAI-compatible provider 验证流式文本、tool call 参数/结果、取消和失败事件；记录模型ID、SDK锁定版本、成功/失败。
3. 接入 assistant-ui 与SSE适配；右侧五组表单实时更新，浅色建议带“AI建议·未采用”标签和采用按钮；保持可读对比度。
4. 编写版本化题库，按已有信息先推荐、再追问。宝宝房采用四类可调整收纳建议，不把四个独立柜子写成既定需求；询问成人陪护需求。
5. 提取需求关联原话；手动填写和采纳写revision；处理版本冲突和重复请求。
6. 独立审查Agent读取证据快照；输出五部分任务书网页和报告JSON。PDF正式导出在Phase2。
7. 准备虚构客厅demo：两人办公、SGD20000且家具口径未知、保留沙发且尺寸未知、喜欢木色不喜欢开放收纳。
8. 完成界面原型、AWS应用部署说明、图像生成可行性小样验证；准备2位室内设计师和1位建筑师访谈提纲，访谈尚未进行则明确记录。
