## 实际运行协议

后端：apps/api/questions.ts + question-options.ts；共享类型与转换：packages/contracts/ask-question.ts；UI：apps/web/src/QuestionCard.tsx，经 ChatWindow 和 Workbench 接入。

每题 A 是待确认推荐或事实补充方法；B/C/D 是其他选择；E 一直提供自由输入。没有预选。现有模型 propose_field 的有效同作用域建议优先成为 A；选 A 时复用 suggestions/adopt，保留原有建议与确认来源。其余确认复用 requirements，逐字段保存，不代表确认整套方案。

金额、币种、尺寸与居住成员不能在缺乏依据时猜测。E 中的范围/解释等自由文本若不能合法写入数值或币种字段，会保留原话继续在当前房间聊天，不强行转成事实。未知/跳过/不适用仍可单独选择。

在草稿期间发生版本更新，保留草稿和旧题，显示最新值，要求显式核对后再提交。跨房间证据不得用于当前房间的推荐；未标作用域的旧聊天不会自动当作全屋事实。
